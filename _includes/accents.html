{% comment %} ===== Site-wide colour accents ===== A small amount of colour so pages don't read as flat black-on-white. Loaded from head.html, so it applies to every page. Hues are mid-tone on purpose: they stay legible on both the light and dark site themes, and the dark block lifts them for contrast. This file also sets the page background: a soft cream in light mode, true black in dark mode, in both cases by overriding the theme's own variables rather than restyling individual elements. Note the :not(.archive__item-title) guards. Publication, talk and teaching listings render each entry's title as an h2, and without the guard every entry in those lists would pick up the heading colour and underline bar. {% endcomment %}
