{% comment %} ===== Cross-fading banner strip ===== Parameters: source "publications" builds slides from the publications collection (any entry with an `image`, newest first). Anything else uses _data/banner.yml. fit "cover" (default) crops photos to fill the strip. "contain" fits the whole image inside it - use for figures, which must not be cropped. ratio width : height of the strip. Default 2.1 for photos, 1.9 for figures. limit maximum slides. Default 6 for publications, all for the data file. Pure CSS: every slide runs the same keyframe animation over the full cycle and is offset by animation-delay, so exactly one is opaque at a time. No JavaScript and no carousel library. {% endcomment %} {% include base_path %} {% assign use_pubs = false %} {% if include.source == "publications" %}{% assign use_pubs = true %}{% endif %} {% if use_pubs %} {% assign limit = include.limit | default: 6 %} {% assign slides = site.publications | where_exp: "p", "p.image" | sort: "date" | reverse %} {% if slides.size > limit %}{% assign slides = slides | slice: 0, limit %}{% endif %} {% assign fit = include.fit | default: "contain" %} {% assign ratio = include.ratio | default: 1.9 %} {% else %} {% assign slides = site.data.banner %} {% if include.limit and slides.size > include.limit %} {% assign slides = slides | slice: 0, include.limit %} {% endif %} {% assign fit = include.fit | default: "cover" %} {% assign ratio = include.ratio | default: 2.1 %} {% endif %} {% if slides and slides.size > 0 %} {% assign slide_seconds = 5 %} {% assign cycle = slides.size | times: slide_seconds %} {% comment %} Share of the cycle one slide holds at full opacity.
