# Bishwa Ranjan Si — Academic Website

Private draft of a responsive academic website inspired by the Academic Website Template selected during design review.

## Pages

- Home
- About
- Research
- Publications with live filtering
- Expandable Topics section

## Editing

The website is intentionally static so it can be hosted directly with GitHub Pages. Edit the HTML files for content, `assets/css/site.css` for the visual design, and `assets/js/site-static.js` for navigation, dark mode, and publication filtering.

The site has not been published. When approved, the selected files can be placed in a `rbishwa.github.io` repository and GitHub Pages can serve them from the repository root.
